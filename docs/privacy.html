Privacy Policy: SRA Bhakti Uploader

Last updated: November 1, 2026

SRA Bhakti Uploader is a private tool used only by the owner of the SRA Bhakti YouTube channel to upload videos to that channel and read that channel's own analytics. It is not offered to the public.

Data we access

Through the YouTube Data API and YouTube Analytics API, the tool accesses only the owner's own channel: uploading videos, setting their titles, descriptions and thumbnails, and reading view, watch-time and retention statistics.

How data is used and stored

Data is used only to publish the channel's videos and to improve future videos. OAuth tokens are stored as encrypted secrets and never shared, sold or transferred to anyone. No data from other users is collected.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see the Google Privacy Policy. Access can be revoked at any time at myaccount.google.com/permissions.
